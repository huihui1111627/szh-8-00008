# 舞台机械联排控制系统

为大型剧院的多组升降台、旋转舞台、吊杆与演员走位建立的联排控制场景原型。
纯前端、零依赖，直接用浏览器打开 `index.html` 即可（也可 `python3 -m http.server` 后访问）。

## 功能

- **同步时间轴**：每套机械一条泳道，按运动区间显示动作块；底部红色斜纹泳道为冲突片段。
- **拖拽重排**：拖动动作块改起止时间，拖右缘改速度/时长；同套机械后续动作立即级联重排。
- **临时停顿**：选中动作后点「⏸ 插入停顿」（或检查器按钮），在播放头处插入 2s 停顿，后续动作顺延；停顿在块上以斜纹段显示，可单独删除。
- **立即重算与预演**：任何调整后即时重算运动学与冲突；「▶ 预演」按 0.5×/1×/2× 回放整个转场，舞台俯视图同步显示机械位置、吊杆高度、旋转角度、演员位置与危险扇区。
- **安全联锁拦截**：按 0.25s 步长做几何冲突检测（安全距离膨胀 + 旋转台扇区扫掠），覆盖
  吊杆低位×演员未离场、升降台高位×吊杆低位、升降/旋转×演员、机械路径交叉等场景。
  存在冲突时「🔒 执行」被阻止，横幅给出最早冲突时间，侧栏冲突项或泳道片段点击即定位。
- **场记点恢复**：播放到关键点「🚩 确认场记点」（快捷键 M），中断后「⏮ 场记恢复」从最近场记点继续；状态写入 localStorage，刷新后仍在。
- **多版本并排**：侧栏「版本」保存快照，可将任意两版（或当前工作版 vs 历史版本）并排同步回放，
  迷你时间轴叠加冲突条，顶部给出节奏差（总时长）与风险窗口差（冲突累计秒数）。

## 操作速查

| 操作 | 方式 |
| --- | --- |
| 预演/暂停 | 空格 或「▶ 预演」 |
| 移动动作 | 鼠标拖动动作块 |
| 改变速度 | 拖动动作块右缘，或检查器中改速度/时长 |
| 插入停顿 | 选中动作 →「⏸ 插入停顿」（在播放头处） |
| 删除动作 | 选中后按 Delete 或检查器按钮 |
| 确认场记点 | M 键或「🚩 确认场记点」 |
| 定位冲突 | 点击右侧冲突列表或时间轴红纹片段 |
| 缩放时间轴 | 右上 －/＋/适应 |

## 文件

- `index.html` — 界面结构
- `styles.css` — 深色控制台样式
- `app.js` — 运动学模型、几何冲突检测、时间轴、回放、场记、版本对比
