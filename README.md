# 舞台机械联排控制台

面向大型剧院的多机械（升降台 ×2、旋转舞台、吊杆 ×2、演员走位 ×2）时间轴联排原型。
零依赖、无构建步骤，直接用浏览器打开 `index.html` 即可。

## 功能

- **统一时间轴**：每套机械/演员一条轨道，片段显示运动区间，红色虚框标出冲突时段。
- **拖拽编排**：拖动片段改起止时间，拖右缘改时长（等价改速度）；同轨道后续动作按原节奏自动整体重排，相邻动作自动保留 0.5s 安全间隔。
- **检视面板**：精确输入起点/终点/目标位/时长，一键在动作中点插入 2s 临时停顿（自动切成“运动—保持—运动”三段，后续顺延），可删除动作。
- **实时安全引擎**（0.1s 采样）覆盖：
  - 演员尚未离开升降台/转盘/吊杆危险区域即启动机械（阻止）
  - 两台升降台同时运动且净距不足 2m（阻止）
  - 升降台运动时与转盘外缘净距不足 1.5m（阻止）
  - 吊杆低位时升降台/转盘仍在运动，净高不足 2.5m（阻止）
  - 吊杆在有人区域低于 2.5m 运行（阻止）
- **执行门控**：存在阻止级冲突时“执行”被锁定，自动跳转并高亮首个冲突片段；无冲突才允许跑整场。
- **舞台预演**：俯视 SVG 实时呈现升降台高度、转盘角度指针、吊杆横梁高度、演员位置，冲突中的资源描红。
- **场记点恢复**：任意时刻“标记场记点”，中断排练后一键回到最近确认点。
- **版本并排回放**：存版本 → 调整 → 打开并排视图，两个版本同步时钟回放；显示各自时长、风险指标与逐资源节奏差异表。
- **持久化**：版本与场记点自动保存在 `localStorage`。

## 运行

```bash
# 直接打开
open index.html

# 或起个静态服务
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 测试

纯逻辑（重排、停顿、冲突检测、场记点、版本 diff）在 `js/core.js`，可用 Node 直接测：

```bash
npm test          # node --test test/core.test.js（8 个用例）
```

## 目录结构

- `index.html` — 布局
- `css/app.css` — 深色控制台主题
- `js/core.js` — 纯逻辑核心（无 DOM 依赖，Node/浏览器通用）
- `js/stage.js` — 舞台 SVG 渲染
- `js/app.js` — 时间轴、拖拽、预演、场记点、版本对比 UI
- `test/core.test.js` — 核心逻辑测试

初始场次（“v1 · 导演初排”）故意保留 11 处典型冲突，用于演示定位与消解流程。
